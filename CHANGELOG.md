# Xool Files changelog

Created by **Vyxen Apps**. [VyxenApps on GitHub](https://github.com/VyxenApps)

## 0.1.0

- Windows file manager with tabs, split panes, multiple folder views, and session restore.
- Customizable sidebar with favorites, groups, recent files, and Recycle Bin access.
- Local and system-wide searches, path history, extension and type filters, and a local index.
- Media previews and plain-text editing within the preview pane.
- Themes, translucent backgrounds, customizable shortcuts, and reorderable shortcuts in the context menu.
- Configurable status bar position. Middle-clicking the last tab follows the window close settings.
- A `XoolFiles` data profile with direct access to its folder from **About**.
- Context menu actions to restore items and empty the Recycle Bin.
- Workspaces with pinned shortcuts, dividers, and a resizable panel.
- An optional active-tab gradient with configurable intensity and border.
